
# Week 5: DOM Manipulation

## About This Project

This project was completed as part of the IYF Season 12 Web Development training.

It focuses on JavaScript DOM manipulation, event handling and building interactive web pages.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Main Project: To-Do List

The To-Do List application allows users to:

- Add tasks using a button or Enter key.
- Mark tasks as completed or undo completion.
- Delete individual tasks.
- Filter tasks by All, Active and Completed.
- View the number of remaining tasks.
- Clear all completed tasks.
- Edit tasks by double-clicking them.
- Save edits using Enter or cancel using Escape.

## Daily Challenges

1. Random Heading Colors
2. Create HTML Elements
3. Remove HTML Elements
4. Copy Content
5. Dark Mode Toggle

## DOM Practice

Additional exercises covered:

- Selecting HTML elements using different DOM methods.
- Modifying HTML content and attributes.
- Creating and removing elements.
- Changing CSS classes dynamically.
- Handling click, keyboard and input events.
- Event delegation.
- Client-side form validation.

## Learning Outcomes

Through this project, I practised selecting, creating, modifying and removing DOM elements, handling user interactions and building interactive web applications using JavaScript.
